# Thư mục file VPA

Tải file Excel danh sách biển VPA (file phiên, file kho ô tô / xe máy) vào thư mục này.
GitHub sẽ tự đọc file và cập nhật tab **Biển VPA** trong trang /admin sau khoảng 2–3 phút.

- File phiên: có các cột `Năm`, `Phiên`, `Địa phương`, `Biển số` (mỗi sheet một loại xe).
- File kho: 1 cột biển số; tên file có chữ `Oto`/`Moto` và `kho`.
- Khi có phiên mới: xóa file phiên cũ, tải file phiên mới lên.
